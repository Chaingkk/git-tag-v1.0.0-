# IGU17 第三方 Modbus 调试工具

商用多联机系统第三方 Modbus 调试工具，支持串口 RTU 和 TCP。

## 功能

- 内机 1~64：存在/在线/开关/室温/故障码/匹数/能力需求/设定温度/模式/风速/控制模式
- 外机 1~4：压力、温度、变频压机、风机、阀开度、加热带、故障、功率
- 通信参数 5000~5003 读写
- CSV 点表驱动
- 配置自动保存
- 连接后自动轮询
- 写操作后自动读回验证
- 外机故障位双击展开
- 原始帧日志，可导出 TXT

## 本地运行

```bash
pip install -r requirements.txt
python modbus_igu17_debugger.py
